## Request

> Let's plan a feature: export tasks to CSV, so I can open them in a spreadsheet.

## Intent

Getting tasks into a spreadsheet for sorting and sharing. Affects the `tasks.py` command line.

## Goals and non-goals

* Goal: `tasks.py export --csv` prints every task as CSV, with a header row `number,title,done`.
* Non-goal: importing CSV.

## Alternatives considered

* Exporting JSON: rejected, since spreadsheets open CSV directly.

## Design

A new `export.py` module writes the tasks with the standard `csv` module. `tasks.py` adds an `export` subcommand that calls it.

## Architecture change

Add `export.py` to Components: it writes tasks as CSV, and `tasks.py export` calls it.

## Areas of concern

* Titles with commas or quotes: the `csv` module quotes them.

## Deferred

None

## Open questions

* Should the export include tasks that are done?
