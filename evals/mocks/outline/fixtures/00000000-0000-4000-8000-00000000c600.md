Status: approved

## Request

> Let's plan a feature: export tasks to CSV, so I can open them in a spreadsheet.

## Intent

Getting tasks into a spreadsheet for sorting and sharing. Affects the `tasks.py` command line. Standard library only.

## Goals and non-goals

* Goal: `tasks.py export` prints every task as CSV, with a header row `number,title,done`.
* Goal: `tasks.py export --output <path>` writes the same CSV to a file.
* Non-goal: importing CSV.

## Alternatives considered

* Exporting JSON: rejected, since spreadsheets open CSV directly.

## Design

A new `export.py` module writes the tasks with the standard `csv` module, and `tasks.py` adds an `export` subcommand that calls it. Two slices, in this order:

1. **Print tasks as CSV with `tasks.py export`.** `export.py` writes every task to stdout, with the header row. Tested by a behavioral test that runs `tasks.py export` against a scratch `tasks.json` with a title containing a comma, and checks the output.
2. **Write the CSV export to a file with `--output`.** `tasks.py export --output <path>` writes the same CSV to the file instead of stdout. Needs the first slice. Tested by a behavioral test that runs it and reads the file.

Neither slice needs a manual test: the behavioral tests observe everything.

## Architecture change

Add `export.py` to Components: it writes tasks as CSV, and `tasks.py export` calls it.

## Areas of concern

* Titles with commas or quotes: the `csv` module quotes them.
