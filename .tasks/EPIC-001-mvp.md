# EPIC-001: MVP

## Goal

Ship the v1 LLM-driven SDLC toolkit specified in [SPEC-001](specs/SPEC-001-llm-sdlc-workflow.md):
the three-artifact data model, a deterministic stdlib `sync` script, and all five skills — proven
by this repo managing its own `.tasks/` end to end.

## In scope

- Per-project `guidelines.md` + `config.md`, and spec/epic/task templates.
- `sync`: frontmatter parser, generated-region engine, epic-status derivation, board renderers,
  the TODO merge, `next-id`, `archive`, and `check`.
- An end-to-end idempotency + derivation-matrix test suite.
- Skills: `init`, `add-task`, `implement-task`, `refine-backlog`, `plan-feature`.
- Dogfooding this repo onto the toolkit and a CI job running `sync check`.

## Out of scope

- Extracting the toolkit into a reusable global workflow (a follow-on spec, per SPEC-001
  Non-goals).
- Sub-tasks, estimates, cycle-time metrics, sprints (SPEC-001 Non-goals).

## Success criteria

- [ ] SPEC-001 §"Success criteria" all satisfied.
- [ ] First `sync` run on this repo is a no-op against the hand-written generated regions
      (TASK-019).
- [ ] `sync check` runs in CI on every PR (TASK-020).
