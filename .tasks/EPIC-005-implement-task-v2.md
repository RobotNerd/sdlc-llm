# EPIC-005: implement-task v2: prose-only rewrite

## Goal

A from-scratch `implement-task-v2` skill: a prose-only `SKILL.md` plus `references/` docs. It runs every invocation as a validated batch, with one local branch per task, TDD/BDD, a haiku critic gating a local squash merge and push, resumable pauses, capped follow-up creation, and per-task/per-batch reports. It sits next to v1 until the human cuts over.

## In scope

- `.claude/skills/implement-task-v2/SKILL.md` with the 11 named steps, and its seven `references/*.md` docs.
- Batch building from all argument forms, with validation, and the `.tmp/batch-state-v2.json` batch state.
- Critic subagent gating, with a rework loop bounded by `critic_rejection_attempts`.
- Interrupt pause/resume keyed by human-readable step names, and the usage safety valve.
- Unregistering only `pretooluse_bash.py` in this repo's `.claude/settings.json`.
- Docs updates, and removing the v1-only keys from `.tasks/config.md`.

## Out of scope

- Python scripts for v2. The automation candidates in SPEC-005 get planned later.
- Renaming v2 to `implement-task`, or removing v1. The human does this cutover.
- New guardrail hooks, and any change to the init-project templates.

## Success criteria

- [ ] Running `/implement-task-v2` with no argument takes the top TODO task through to a squash commit pushed to `main`, a critic approval, and a report in `reports/`.
- [ ] Every batch argument form resolves or is refused with a clear reason before any work starts.
- [ ] A paused or lost-session batch resumes from its recorded step name.
- [ ] `sync check` and the full test suite pass after every task.
